## ⚙️ **Installation & Setup**

### **Prerequisites**
- Node.js 18+ 
- MongoDB database
- Stripe account
- Email service (Resend recommended)

### **Detailed Setup**

<details>
<summary><strong>📋 Step-by-Step Guide</strong></summary>

#### 1. **Clone Repository**
```bash
git clone https://github.com/yourusername/startup-growth-kit.git
cd startup-growth-kit
```

#### 2. **Install Dependencies**
```bash
npm install
```

#### 3. **Environment Variables**
Create `.env.local` file:
```bash
# ==========================================
# 🚀 STARTUP GROWTH KIT - ENVIRONMENT CONFIG
# ==========================================
# Copy this file to .env.local and fill in your actual values
# Never commit .env.local to version control!

# ==========================================
# 📊 DATABASE CONFIGURATION
# ==========================================
# MongoDB connection string - get from MongoDB Atlas or local instance
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/
DATABASE_NAME=startup_growth_kit

# ==========================================
# 🔐 AUTHENTICATION & SECURITY  
# ==========================================
# Generate a strong secret: openssl rand -base64 32
JWT_SECRET=your-super-secret-jwt-key-here
NEXTAUTH_SECRET=your-nextauth-secret-key-here

# Your application URLs
NEXTAUTH_URL=http://localhost:3000
NEXT_PUBLIC_BASE_URL=http://localhost:3000
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# ==========================================
# 💳 PAYMENT PROCESSING
# ==========================================

# Stripe Configuration (Primary Payment Processor)
# Get these from: https://dashboard.stripe.com/apikeys
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_your_stripe_publishable_key_here
STRIPE_SECRET_KEY=sk_test_your_stripe_secret_key_here

# Stripe Webhook Secret (for payment confirmations)
# Get from: https://dashboard.stripe.com/webhooks
STRIPE_WEBHOOK_SECRET=whsec_your_stripe_webhook_secret_here

# LemonSqueezy Configuration (Alternative Payment Processor)  
# Get webhook secret from: https://app.lemonsqueezy.com/webhooks
LEMONSQUEEZY_WEBHOOK_SECRET=your_lemonsqueezy_webhook_secret_here

# ==========================================
# 📧 EMAIL SERVICES
# ==========================================
# Resend API for transactional emails
# Get API key from: https://resend.com/api-keys
RESEND_API_KEY=re_your_resend_api_key_here
RESEND_FROM_EMAIL=noreply@yourdomain.com

# ==========================================
# 🔗 OAUTH PROVIDERS
# ==========================================

# Google OAuth (Sign in with Google)
# Get credentials from: https://console.developers.google.com/
GOOGLE_CLIENT_ID=your_google_client_id_here.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_google_client_secret_here

# GitHub OAuth (Sign in with GitHub)  
# Get credentials from: https://github.com/settings/applications/new
GITHUB_CLIENT_ID=your_github_client_id_here
GITHUB_CLIENT_SECRET=your_github_client_secret_here

# ==========================================
# 🛠️ OPTIONAL CONFIGURATIONS
# ==========================================

# Environment (development, staging, production)
NODE_ENV=development

# Admin Configuration (for initial setup)
ADMIN_EMAIL=admin@yourdomain.com
ADMIN_PASSWORD=change-this-secure-password

# Analytics & Monitoring (optional)
# GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
# SENTRY_DSN=https://your-sentry-dsn-here

# ==========================================
# 📝 SETUP INSTRUCTIONS
# ==========================================
# 1. Copy this file: cp .env.example .env.local
# 2. Fill in all the values above with your actual credentials  
# 3. Never commit .env.local to git (it's in .gitignore)
# 4. For production, set these as environment variables in your hosting provider
#
# 🔗 Helpful Links:
# MongoDB Atlas: https://www.mongodb.com/cloud/atlas
# Stripe Dashboard: https://dashboard.stripe.com/
# Resend: https://resend.com/
# Google Console: https://console.developers.google.com/
# GitHub Apps: https://github.com/settings/applications/new
```

#### 4. **Database Setup**
```bash
# Seed initial data
npm run seed
```

#### 5. **Development**
```bash
npm run dev
# Open http://localhost:3000
```

#### 6. **Production Build**
```bash
npm run build
npm start
```

</details>
